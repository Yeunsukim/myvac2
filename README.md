# 나만의 단어장

모바일 중심의 개인용 의학용어/영어 단어장 웹앱입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## 포함 기능
- 책갈피 생성/이름 변경/삭제
- 단어 등록/수정/삭제
- 등록일 저장
- 책갈피별 단어장
- 최신/과거/알파벳 정렬
- 카드 뒤집기 학습
- 이전/다음 단어
- 좌우 스와이프
- 영어 TTS
- LocalStorage 저장

## GitHub Pages
GitHub 저장소의 루트에 `index.html`, `style.css`, `app.js`를 올린 뒤
Settings → Pages → Build and deployment → Source에서 `Deploy from a branch`,
Branch는 `main`, 폴더는 `/(root)`를 선택하면 됩니다.
